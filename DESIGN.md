# Docket Scout: UI direction ("Scouting report")

Picked by the author from three rendered directions (Departures board, Expedition map, Scouting report); the renders are kept outside the repo.

**References** (principles only, nothing copied): basedash.com (dense data in calm panels), felt.com (paper tones, map-first restraint), vestaboard.com (a display as an information object), antimetal.com (restrained light canvas).

**Own metaphor: the builder is the player, hackathons are fixtures.**
- The left card is a football-style player card for any GitHub user: position chips (strongest skills), six attributes from their repos, the trophy cabinet read from their profile README, and their record per skill from H-MEM.
- The right side is this week's fixtures: "You vs PayPal AI Hackathon", kick-off (days to the deadline), a match rating (fit), START / BENCH / OUT, expected dollars per build hour, and the line-up (the repo that gives a head start).
- A scout's note says the one thing worth saying out loud; the scout log lists merges, currency conversions, moved deadlines and skips.
- While a run is live, a match-day strip shows each agent taking its turn.

## Tokens
- Canvas `#f6f6f2`, ink `#101410`, pitch `#0f5c3a` / `#157a4d`, chalk `#e9f5ec`, lime `#c6f24e`, amber `#d4a017`, red `#e2412b`.
- Type: Barlow Condensed 700–800 (uppercase headings, numbers), Barlow (body), IBM Plex Mono (labels, money, query ids).
- Radius 14–22px, hairline borders, one soft shadow on START fixtures only.
